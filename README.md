# Bioinformatics & Precision Oncology: Scientific Writing Portfolio

## Overview

A curated collection of academic writing samples demonstrating professional scientific communication in cancer bioinformatics and precision oncology research. This repository showcases drafted abstracts, detailed computational methodologies spanning **Bulk RNA-seq** and **single-cell RNA-seq (scRNA-seq)** pipelines, results interpretation and discussion sections, and peer-reviewed journal cover letters.

The portfolio reflects rigorous training in translating complex multi-omic computational analyses — differential expression modeling, functional pathway enrichment, protein-protein interaction networks, survival meta-analysis, and tumor microenvironment deconvolution — into clear, publication-ready scientific prose suitable for high-impact journals.

## 🔬 Writing Domains Covered

- **Bulk RNA-Seq Methodology:** DESeq2/edgeR differential expression, GO/KEGG/Reactome enrichment, PPI network biology, Kaplan-Meier & Cox proportional hazards analysis, REML random-effects meta-analysis.
- **Single-Cell RNA-Seq Methodology:** Seurat QC/clustering, SingleR annotation, CopyKAT CNV inference, CellChat ligand-receptor communication, Monocle3 trajectory inference, SCENIC regulon analysis, Harmony batch integration.
- **Clinical Reporting:** Hazard ratios with 95% confidence intervals, log-rank testing, forest plot interpretation, cross-cohort validation frameworks.
- **Journal Communication:** Editorially targeted cover letters emphasizing novelty, methodological rigor, and clinical relevance.
